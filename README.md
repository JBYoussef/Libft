# Libft

This repository currently contains the project README and serves as the starting point for the **Libft** library.

## Project goal

Libft is intended to be a custom C utility library that reimplements common standard-library behaviors (string handling, memory helpers, and linked-list utilities) as a reusable base for future C projects.
